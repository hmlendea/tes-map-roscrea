## 🔎 What This Document Covers

This document describes how TES Map - Roscrea at https://github.com/hmlendea/tes-map-roscrea handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 📥 Data We Handle

### Data Provided to the Application

No personal data is requested or provided to the application. This project is a static map artwork asset (XCF file) with no runtime component.

### Data Generated or Collected by the Application

No personal data is generated or collected automatically. The project has no runtime, telemetry, crash reporting, or update-check mechanisms.

### Data Received from Integrations

No personal data is received from integrations or third parties. The project has no built-in integrations.

## 🧭 Processing and Use

The application processes no personal data. This project is a static asset distributed for use in The Elder Scrolls IV: Oblivion modding.

## 🗄️ Storage, Retention, and Deletion

No personal data is stored by the project. The repository contains only the map artwork source file (Roscrea.xcf), documentation, and configuration files. Users who download the mod from Nexus Mods receive only the exported texture assets.

## 🔗 External Processing and Integrations

The application has no built-in external data transfer. Distribution occurs through Nexus Mods (https://nexusmods.com/oblivion/mods/53055), which operates under its own privacy policy. The project maintainers do not receive personal data through this distribution channel.

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| Nexus Mods | Mod distribution | None from this project | https://nexusmods.com/oblivion/mods/53055 |

## 🛡️ Data Protection and Security

No personal data is processed, so no specific safeguards are required for this project. The repository is public on GitHub. Downstream forks and modifications are not the responsibility of the original maintainers.
